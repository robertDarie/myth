THRONES OF MYTH - PRIVATE ALPHA CLIENT

Extract the entire ZIP before running Start Thrones of Myth Online.cmd.
This starts only the game. It never starts Node or a local server.
The host must keep the dedicated server running.

Enter the HTTPS address supplied by your host in Connection settings.
Click Refresh kingdoms, select the shared kingdom, enter the invitation code,
choose a city name/civilization and enter. Keep the same name and address to
resume the saved local session. Use a protected account for another computer.
Never share passwords, recovery codes or session tokens.

The host address and invitation are supplied separately, never embedded here.
Optional direct launch from PowerShell:
  .\Game\ThronesOfMyth.exe --thrones-client-only --thrones-server https://HOSTNAME

A protocol or source-build mismatch needs the matching client ZIP and server.
If the host is offline, no shared gameplay is available. Do not start a separate
local kingdom as a replacement for the host's persistent world.

This is an alpha. Real remote 3-10-player gameplay still needs verification.
