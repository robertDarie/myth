# Unverified mechanics — evidence still required

This is an initial blocker list, not a claim that every numerical subsystem has been audited.

- City/buildings: every reference level's costs, seconds, prerequisites, production/capacity, speed/help stacking and unlocks. Need independently checked client tables/screenshots, mode/build, and consolidation mapping. The available index alone cannot supply these.
- Troops: generic versus civilization-special T1–T5 values, four classes including siege, facility capacity and promotion accounting. Need class/tier-keyed tables and independent evidence; the accessible table contains a suspicious duplicate T1 Spearman entry.
- Marches: full commander contribution schedule, building/research/skills/talents/buffs and stacking, rallies and reinforcement. Need representative measured marches with each modifier isolated.
- Combat: internal attack/defense/health damage equation, counter and damage-type interactions, rage/timing, target rules, casualties by mode. Need controlled repeated reference combats, logs and uncertainty analysis. Matching displayed power or a single damage result is insufficient.
- Commanders: all rarity XP rows, star upgrade probabilities/item costs, complete talent point schedule/tree prerequisites, skill selection/reset/expertise, primary/secondary equipment and active ordering. Need current build screenshots and isolated controlled comparisons. Published 74-point endpoint is not a full progression specification.
- Research: economy/military level tables and prerequisites including T5, stacking and research speed. Need per-technology mapping; 17 local technologies do not imply 17 RoK equivalents.
- Economy: production/node rates, load/delivery, storage protection, taxes, offline clock, cost/reward trajectories. Need units and normalized governor modifiers; Unity metres are not reference map units.
- Hospitals: all building/tier capacities, healing costs/durations, help, severe/light/dead/overflow treatment by PvE/PvP/structure mode. Need conservation observations, not an assumed universal casualty percentage.
- Ordinary PvE: complete fresh 1–25 cross-check of source fixtures, conflicting early XP, recommended versus actual troops, loot quantities versus drop probabilities, discounts/chaining and search/respawn conditions. Hidden probabilities remain UNKNOWN.
- Special PvE: forts, keeps, war camps, guardians, bosses, Marauders and encampments need separate mode/event requirements and numeric tables.
- Population: exact reference density, spawn probability, patrol radius, pursuit and respawn algorithm remain UNKNOWN. Local radius 3 and speed .7 are original rules, not newly verified reference data.
- Alliances: membership growth, roles/help, technology/donations, credits/gifts, territory/flags/fortresses, rallies, reinforcement and diplomacy. Need technology/structure-dependent limits; fixed local membership 100 is not a verified universal reference cap.
- Kingdom: home-kingdom versus KvK/coalition pass access, opening stages, defender/capture rules and central objectives. Need mode-specific topology and current observations. Scouts and armies require distinct policies.
- Events/seasons: schedule, score/reset/claim rules, rank rewards and eligibility. The local 28-day season remains separate from KvK.
- Items/premium-adjacent mechanics: speedups, AP items, teleports, buffs, shards/sculptures, equipment materials, VIP and summon odds/pity. Need exact category/item version evidence. Local monetization and currencies are not changed by this audit.
- Scouting: all camp levels, counts, speed, discovery/investigation rewards, recon privacy and pass exceptions. Need measured route/queue behavior plus persistent fog tests.

Task 3 still requires the full feature inventory, remaining matrices, simulations, workbook and independent review. Task 4 will supply functional observations but cannot manufacture missing RoK reference evidence.
